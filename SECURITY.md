# Security Policy

## Reporting Vulnerabilities

Report suspected security vulnerabilities through GitHub private vulnerability
reporting, not public issues. [Submit a private vulnerability report](https://github.com/TrapsterDK/rules_dx/security/advisories/new)
or use **Security > Advisories > Report a vulnerability** on the project repository.
Private vulnerability reporting is enabled. Ordinary non-security bugs belong in GitHub issues.

Include the affected version, impact, and minimal reproduction steps. Do not include
credentials or unrelated private data. Maintainers coordinate investigation and fixes
privately with the reporter before publishing an advisory with affected versions and
remediation guidance.

## Supported Versions

No release exists yet. Once releases exist, fixes follow the
[latest-release-only maintenance policy](docs/environments/environment.md#distribution).
