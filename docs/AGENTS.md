# Documentation Instructions

- User docs live in `docs/cli/commands/`, `docs/github-ci.md`, and short READMEs. Nothing else is user docs.
- Do not keep design rationale, alternatives, history, or cross-links to it. Delete those files and paragraphs instead of updating them.
- One page per command or task. Short sentences. Delete anything a user does not need to type or decide.
- Never add `See:`/`Contract:` chains, issue numbers, or links to deleted internals to justify text.
