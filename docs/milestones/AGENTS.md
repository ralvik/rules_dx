# Milestone Documentation Instructions

- `README.md` owns order, status, deps, entry/exit, and reports. `Ready` means deps-ready, not release-ready. A user request starts work; log open gates as gaps.
- Spec format: one H1, then Outcome, Scope, Contract References, Deliverables, Work Packages, Milestone-Specific Evidence, Out Of Scope, Completion Report Additions.
- Keep specs short; link contracts and tests.
- Only milestone-specific evidence; don't repeat common rules.
- Keep capability terms as defined; don't redefine them.
- Use `../decisions/`, `../architecture/`, `../cli/`, and other domain paths.
- Copy `TEMPLATE.md` for new milestones; add to the index.
